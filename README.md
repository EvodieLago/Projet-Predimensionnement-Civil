# Projet Final - Genie Civil L2

## Description

Programme de predimensionnement en genie civil.

## Fonctionnalites

- Saisie et chargement d'un projet
- Calcul des charges ELU et ELS
- Descente de charges
- Predimensionnement des poteaux
- Predimensionnement des semelles
- Generation du devis
- Exportation d'un rapport

## Technologies

- Python
- JSON
- Git
- GitHub

## Lancement

Depuis le dossier principal :

python src/main.py

## Tests

python -m unittest discover -s tests
